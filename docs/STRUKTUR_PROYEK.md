# Struktur Proyek

Repositori Portfolio Open Source digunakan untuk mendokumentasikan proses pembelajaran dan penerapan Git dalam pengelolaan proyek.

## Susunan Direktori

- `.gitignore`: Mengatur file dan folder yang tidak perlu dilacak Git.
- `README.md`: Berisi profil mahasiswa, ketertarikan, dan tujuan pembelajaran.
- `CONTRIBUTING.md`: Berisi panduan kontribusi terhadap proyek.
- `docs/`: Menyimpan dokumentasi tambahan proyek.
- `docs/STRUKTUR_PROYEK.md`: Menjelaskan susunan dan fungsi setiap bagian repositori.

## Pengelolaan Versi

Proyek ini menggunakan Git untuk mencatat perubahan melalui commit. Branch digunakan untuk mengembangkan fitur secara terpisah sebelum digabungkan ke branch utama.

## Tujuan Dokumentasi

Dokumentasi ini membantu pengguna memahami isi repositori dan mempermudah pemeliharaan proyek pada pengembangan berikutnya.
