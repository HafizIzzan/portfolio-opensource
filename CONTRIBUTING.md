# Panduan Kontribusi

Dokumen ini menjelaskan panduan sederhana untuk berkontribusi pada proyek Portfolio Open Source.

## Persiapan

1. Pastikan Git sudah terpasang.
2. Siapkan akun GitHub.
3. Pelajari struktur repositori sebelum melakukan perubahan.

## Alur Kontribusi

1. Fork repositori apabila berkontribusi melalui GitHub.
2. Buat branch baru sesuai fitur atau perbaikan yang dikerjakan.
3. Lakukan perubahan pada file yang relevan.
4. Periksa kembali perubahan sebelum disimpan.
5. Gunakan commit message yang jelas dan menggambarkan perubahan.
6. Ajukan Pull Request untuk proses peninjauan.

## Aturan Penulisan

- Gunakan nama file yang jelas.
- Tulis dokumentasi dengan bahasa yang mudah dipahami.
- Hindari memasukkan password, token, atau informasi pribadi ke repositori.
- Pastikan perubahan sesuai tujuan proyek.

## Tujuan

Panduan ini dibuat untuk membiasakan penggunaan alur kerja kolaboratif dalam pengembangan proyek Open Source.
